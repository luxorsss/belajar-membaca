# Belajar Mengenal Huruf untuk Balita 🎈

Aplikasi web interaktif ramah balita untuk belajar mengenal 26 huruf alfabet (A-Z) dengan metode fonik bertahap, suara audio AI Indonesia yang jernih, dan visual flashcard 1 layar 1 huruf bebas distraksi.

## Fitur Utama
- **5 Tahap Fonik Terstruktur:**
  - **Tahap 1:** Vokal Dasar (`A, I, U, E, O`)
  - **Tahap 2:** Konsonan Awal Bibir & Lidah (`B, M, P, T, N`)
  - **Tahap 3:** Konsonan Lembut & Alir (`D, L, S, K, G`)
  - **Tahap 4:** Konsonan Tengah & Getar (`H, J, C, R, W`)
  - **Tahap 5:** Konsonan Khusus & Serapan (`Y, F, V, Z, Q, X`)
- **Flashcard Ramah Anak:** 1 Layar = 1 Huruf besar murni tanpa kata/gambar yang mengaburkan fokus.
- **Audio Suara Asli:** Bunyi vokal & konsonan jernih dalam bahasa Indonesia.
- **Kuis Tebak Huruf:** Menguji pendengaran balita dengan feedback visual membal dan konfeti.
- **100% Statis:** Berjalan langsung di browser tanpa perlu server backend.
